# Markdown Example

This file demonstrates common Markdown syntax you can use in `.md` files.

## Headings

# H1
## H2
### H3

## Text Formatting

**Bold text**, *italic text*, ***bold italic***, ~~strikethrough~~, and `inline code`.

## Lists

**Unordered:**
- First item
- Second item
  - Nested item
- Third item

**Ordered:**
1. Step one
2. Step two
3. Step three

**Task list:**
- [x] Completed task
- [ ] Pending task
